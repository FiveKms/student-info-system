# 学生信息管理系统（软件测试练手项目）

一个用 **Python + SQLite** 编写的学生信息管理系统，使用 **unittest** 编写单元测试，适合作为软件测试方向的学习与简历项目。

## ✨ 功能

- 登录校验（正确 / 错误密码、空输入、大小写敏感）
- 学生信息**增删改查**（添加 / 查询 / 修改 / 删除 / 查看全部）
- 输入校验（姓名非空、年龄 0–30 岁）

## 🧪 测试覆盖

- 共 **19 条**单元测试，使用 Python 标准库 `unittest`
- 覆盖 **正常 / 异常 / 边界** 三类情况
- 用例设计方法：**等价类划分** + **边界值分析**

## 📁 项目结构

| 文件 | 说明 |
|---|---|
| `student_manager.py` | 被测系统（核心功能） |
| `test_student_manager.py` | 单元测试 |
| `README.md` | 说明文档 |

## 🚀 运行

环境要求：**Python 3.x**（无第三方依赖，仅用标准库）

```bash
# 功能演示
python student_manager.py

# 运行测试
python test_student_manager.py
```

> Windows 下如果 `python` 命令不识别，请改用 `py`（新版 Python 安装管理器）。

## 📖 学习建议（按顺序）

1. 先读 `student_manager.py`，理解登录与增删改查的实现
2. 再读 `test_student_manager.py`，理解「测试用例 = 输入 + 预期 + 断言」
3. 自己动手：给某个功能补充新用例（如密码含空格、超长用户名）
